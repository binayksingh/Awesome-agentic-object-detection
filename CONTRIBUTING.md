# Contributing

Thank you for helping keep this list current.

1. Check that the paper is not already listed (search the README for its title).
2. Add one row to the matching section of `README.md`, keeping the list sorted newest first:
   `| Year | Title | First author et al. | Venue | [paper](link) |`
   Use the published venue (e.g., CVPR, NeurIPS, a journal) when available; use `arXiv` only for preprints.
3. Add the BibTeX entry to `survey.bib`.
4. Benchmark numbers added to `tables/*.csv` must be the values reported in the original paper, under the protocol stated in `tables/README.md`.
5. Open a pull request with a one-line description.

Alternatively, open an issue using the **Add paper** template.
